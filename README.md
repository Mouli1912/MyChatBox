# MyChatBox
# 💬 Real-Time Chatbox App

My first backend project built using modern web technologies.  
This is a real-time chat application where users can send and receive messages instantly.

## 🚀 Features

- 🔴 Real-time messaging using Socket.io
- 👤 User join/leave notifications
- 💬 Instant message updates
- 🌐 Multiple users can chat together
- 📱 Responsive UI
- ⚡ Fast communication between client and server
- 🔒 Secure backend setup

## 🛠️ Tech Stack

### Frontend:
- HTML
- CSS
- JavaScript

### Backend:
- Node.js
- Express.js
- Socket.io

### Tools:
- Git
- GitHub
- VS Code
